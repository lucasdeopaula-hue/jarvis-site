Política de Privacidade

Última atualização: 3 de outubro de 2026

Esta política explica como o Jarvis, assistente pessoal de voz de uso privado, trata os dados que acessa.

1. Quais dados o app acessa

O Jarvis acessa apenas os eventos do Google Agenda do próprio usuário que autorizou o acesso. Esses dados são usados somente para:

  • ler a agenda do usuário, para informar e lembrar compromissos;
  • criar e atualizar eventos na agenda do próprio usuário, a pedido dele.

O app não acessa e-mails, contatos, arquivos ou qualquer outro dado da Conta Google.

2. Onde os dados ficam

Os dados ficam armazenados no computador do próprio usuário. Não existe servidor do Jarvis guardando informações da agenda.

3. Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros, e não são usados para publicidade.

4. Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso

O usuário pode remover o acesso do Jarvis à Conta Google a qualquer momento:

  1. Acesse myaccount.google.com.
  2. Vá em Segurança > Apps de terceiros (conexões com apps e serviços de terceiros).
  3. Selecione Jarvis e remova o acesso.
